# ☕ راهنمای استفاده — نوین کافه (Novin Cafe)

راهنمای کامل راه‌اندازی، مدیریت و استفاده از سایت. این فایل مرجع همیشگی توئه.

> پروژه: Django 5.2 · پایگاه‌داده SQLite · فارسی/RTL · پوشه‌ی اصلی: `site-cofee/`

---

## ۱) راه‌اندازی و اجرا

### پیش‌نیازها
- Python 3.13
- پکیج‌های لازم: `Django`، `Pillow`، `django-jazzmin`

اگر روی سیستم جدید نصب می‌کنی:
```bash
pip install Django Pillow django-jazzmin
```

### اجرای سایت (سرور توسعه)
از داخل پوشه‌ی پروژه:
```bash
python manage.py runserver
```
سایت روی این آدرس بالا میاد: **http://127.0.0.1:8000/**

برای اجرا روی پورت دلخواه (مثلاً ۸۰۸۰):
```bash
python manage.py runserver 8080
```

برای دسترسی از گوشی/دستگاه دیگر در همان شبکه:
```bash
python manage.py runserver 0.0.0.0:8000
```

### توقف سرور
در همان ترمینال کلید **Ctrl + C** را بزن.

## ۳) ورود مدیر (لاگین)

نام کاربری و رمز پیش‌فرض (از فایل `seed_data.py`):

```
نام کاربری:  admin
رمز عبور:    admin123
```

> ⚠️ **مهم:** حتماً این رمز پیش‌فرض را عوض کن، مخصوصاً قبل از انتشار سایت روی اینترنت:
> ```bash
> python manage.py changepassword admin
> ```

### ساخت مدیر جدید
```bash
python manage.py createsuperuser
```

## ۴) پنل ادمین جنگو — `/admin/`

پنل اصلی و کامل مدیریت (با تم مدرن jazzmin). با `admin/admin123` وارد شو.

**چه کارهایی می‌تونی بکنی:**
- **سفارش‌ها** (`/admin/orders/order/`):
  - دیدن همه‌ی سفارش‌ها با بج رنگی وضعیت
  - تغییر گروهی وضعیت: چند سفارش را تیک بزن → از منوی «اقدام» یکی از این‌ها را انتخاب کن:
    - علامت‌گذاری به: پرداخت شده / در حال برشته‌کاری / ارسال شده / لغو شده
  - جستجو با شماره سفارش، نام، موبایل یا کد رهگیری
  - فیلتر بر اساس وضعیت و تاریخ
- **محصولات فروشگاه** (`/admin/shop/product/`): افزودن/ویرایش محصول، تصویر بندانگشتی، بج موجودی (سبز=کافی، نارنجی=کم، قرمز=ناموجود)، اکشن گروهی فعال/ویژه‌کردن
- **منوی کافه** (`/admin/menu/menuitem/`): مدیریت آیتم‌ها و دسته‌ها
- **رزروها** (`/admin/reservations/tablereservation/`): تایید/لغو گروهی، ثبت پرداخت بیعانه
- **تنظیمات سایت** (`/admin/core/sitesettings/`): نام سایت، رنگ‌ها، روشن/خاموش‌کردن بخش‌ها (لوگوموشن، منو، فروشگاه، رزرو و...)، ساعت کاری و تماس

## ۵) پنل مدیریت سریع — `/management/`

یک داشبورد سبک برای کارهای روزمره (جدا از پنل ادمین جنگو). فقط برای کاربران **کارمند/staff** باز است؛ اگر وارد نشده باشی به صفحه‌ی لاگین می‌رود.

- `/management/` — خلاصه‌ی آمار (تعداد سفارش، رزرو، آیتم منو)
- `/management/orders/` — تغییر سریع وضعیت سفارش‌ها
- `/management/menu/` — روشن/خاموش و ویرایش سریع آیتم‌های منو، افزودن آیتم جدید
- `/management/reservations/` — مدیریت رزروها
- `/management/settings/` — تنظیمات ظاهری و رزرو

---

## ۶) پیگیری سفارش توسط مشتری — `/orders/track/`

مشتری **بدون نیاز به ثبت‌نام یا ورود** سفارشش را پیگیری می‌کند:
1. وارد `/orders/track/` می‌شود (لینکش در نوار بالای سایت: «پیگیری سفارش»)
2. **شماره سفارش** (مثل `NC-10432`) و **شماره موبایلی که موقع خرید ثبت کرده** را وارد می‌کند
3. نتیجه نمایش داده می‌شود:
   - نوار پیشرفت ۴ مرحله‌ای: **ثبت سفارش → پرداخت شد → برشته‌کاری → ارسال شد**
   - کد رهگیری مرسوله، مبلغ، آدرس و لیست اقلام

> نکته: چون سفارش‌ها به اکانت وصل نیستند، پیگیری بر اساس «شماره سفارش + موبایل» انجام می‌شود. اگر موبایل با چیزی که موقع خرید ثبت شده فرق کند، سفارش پیدا نمی‌شود.

**وضعیت‌ها را تو (مدیر) از پنل ادمین یا `/management/orders/` تغییر می‌دهی** و مشتری همان لحظه در صفحه‌ی پیگیری می‌بیند.

## ۷) لوگوموشن صفحه‌ی اصلی

- هر بار که صفحه‌ی اصلی رفرش شود، انیمیشن لوگو (پر شدن فنجان با قهوه) پخش می‌شود.
- روشن/خاموش کردنش: پنل ادمین → تنظیمات سایت → «فعال بودن انیمیشن لندینگ قهوه».
- برای تست/توسعه، توقف انیمیشن روی ثانیه‌ی دلخواه: `http://127.0.0.1:8000/?intro=freeze:2`

## ۸) دستورهای پرکاربرد مدیریت (Management Commands)

```bash
# بررسی سلامت پروژه (خطاها)
python manage.py check

# ساخت و اعمال تغییرات پایگاه‌داده (بعد از تغییر مدل‌ها)
python manage.py makemigrations
python manage.py migrate

# جمع‌آوری فایل‌های استاتیک (هنگام انتشار روی سرور واقعی)
python manage.py collectstatic

# پر کردن دیتابیس با داده‌های اولیه‌ی نمونه
python seed_data.py

# باز کردن کنسول تعاملی جنگو
python manage.py shell
```

## ۹) نکات انتشار روی سرور واقعی (Production)

قبل از اینکه سایت را روی اینترنت بگذاری، در فایل `config/settings.py`:
- `DEBUG = True` را به **`False`** تغییر بده
- `SECRET_KEY` را به یک کلید تصادفی و مخفی جدید عوض کن
- `ALLOWED_HOSTS = ['*']` را به دامنه‌ی واقعی‌ات محدود کن (مثلاً `['cafenovin.ir']`)
- رمز کاربر `admin` را حتماً عوض کن
- `python manage.py collectstatic` را اجرا کن
